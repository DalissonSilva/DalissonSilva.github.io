03 — Pilares

Áreas de Atuação

01

Arquitetura de Dados

Fundação estrutural que sustenta tudo

→Medallion Architecture: Bronze → Silver → Gold com isolamento total entre camadas
→Nomenclatura padronizada: CAMADA.AREA_ENTIDADE aplicada em toda a plataforma
→Isolamento de fontes: somente a camada Bronze tem acesso ao BD transacional de produção
→Particionamento: Parquet Gold particionado por área de negócio para performance analítica
→Rastreabilidade: coluna DT_CARGA em todas as tabelas Bronze para auditoria
02

Engenharia de Dados

Pipelines que não mentem

→Python end-to-end: extração, transformação e carga em scripts versionados no Git
→Airflow: DAGs com dependências explícitas, SLA por tarefa e alertas por e-mail em falha
→Reprocessamento seguro: DT_CARGA permite reprocessar qualquer janela sem duplicação
→Branches por camada: bronze/, silver/, gold/ isolados no repositório Git
→Regras de negócio centralizadas: transformações documentadas e testáveis na camada Silver
03

Governança de Dados

Dado sem dono é dado sem valor

→Data Owners: responsável formal por domínio — Financeiro, Assistencial, Suprimentos
→Dicionário de dados: arquivos .md no Git com definição, tipo e origem de cada campo
→Changelog: histórico de alterações por tabela com data e motivo da mudança
→SLA por área: tempo máximo de entrega documentado e monitorado via Airflow
→LGPD: identificação de dados sensíveis na Silver e controle de acesso por domínio
04

Analytics & BI

Da consulta ao insight executivo

→BI corporativo: migração de BI local para cloud com estrutura de espaços por área de negócio
→Inventário e governança: análise de uso via API de administração — priorização por acesso e criticidade
→Top painéis prioritários: reconstruídos sobre Gold + Parquet com performance otimizada
→Zero join no BI: cada painel consume 1 arquivo Parquet Gold pré-consolidado
→Autoatendimento analítico: espaços por nível — estratégico, gerencial, operacional
05

Dados em Cloud

Escala sem limite Em adoção

→OCI: Object Storage para data lake persistente + Oracle ADW como data warehouse analítico em nuvem
→OCI Data Integration: pipelines gerenciados na nuvem eliminando manutenção de infraestrutura local
→Oracle Data Catalog: governança unificada com linhagem automática e controle de acesso granular
→Oracle Analytics Cloud: BI em nuvem com capacidades de ML integradas sobre os dados da plataforma
→OCI Data Science: rastreamento de experimentos e serving de modelos de ML sobre a plataforma de dados
06

Cultura de Dados

Dado como ativo estratégico Em construção

→Capacitação: workshops internos sobre leitura de dados e uso dos painéis para equipes de negócio
→Self-service analítico: estrutura de espaços no BI que permite exploração autônoma com segurança
→Democratização: dados disponíveis para quem precisa, com controle de acesso adequado por função
→Decisão baseada em evidência: substituição de planilhas manuais por dashboards com fonte única de verdade
→Data Literacy: glossário de termos técnicos e de negócio para alinhamento entre TI e áreas funcionais
